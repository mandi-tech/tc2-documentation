# Comunicação entre Microfrontends

A comunicação entre microfrontends deve ser **mínima, explícita e bem documentada**.

## Estratégias Utilizadas

- Compartilhamento de dependências
- Serviços globais expostos pelo Shell
- Eventos de alto nível (quando necessário)

## Boas Práticas

- Evitar comunicação direta excessiva
- Preferir contratos bem definidos
- Manter baixo acoplamento
