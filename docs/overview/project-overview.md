# Visão Geral do Projeto

O **Tech Challenge – Fase 2** é uma aplicação web desenvolvida utilizando **arquitetura de microfrontends**, com foco em modularidade, escalabilidade e facilidade de manutenção.

O projeto foi implementado com **Angular** e adota o padrão de **Module Federation** para permitir que múltiplas aplicações frontend independentes sejam integradas em tempo de execução.

## Objetivos do Projeto

- Aplicar conceitos modernos de arquitetura frontend
- Garantir independência entre módulos
- Facilitar evolução e manutenção do código
- Simular um ambiente real de desenvolvimento distribuído

## Tecnologias Utilizadas

- Angular
- Angular CLI
- Module Federation
- TypeScript
- Git / GitHub

## Visão Geral

A aplicação é composta por um **Shell (Host)** e múltiplos **microfrontends**, cada um responsável por um domínio específico do sistema.
